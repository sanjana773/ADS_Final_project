ABOUT THE PROJECT

Deep Learning Based Plant Disease Detection Detection

The Plant Disease Detection System is a Data Science project developed to identify plant diseases from images using deep learning and image classification techniques. The system provides a simple web-based interface where users can upload plant images and receive a prediction based on the trained deep learning model.

The system allows users to upload an image of a plant leaf or tomato and receive a predicted disease classification from a trained model.

Project Overview

Plant diseases can affect the growth, quality, and overall health of crops. Identifying diseases at an early stage can help in taking appropriate measures to protect plants. This project focuses on detecting common tomato plant diseases by analyzing visual patterns present in uploaded images.

The system uses image processing and deep learning techniques to learn patterns from a collection of training images. After training, the model can analyze a new image and classify it into one of the disease or health categories it has learned.

The project includes two types of image detection. Tomato leaf images are analyzed to identify different leaf diseases, while tomato fruit images are classified as healthy or rotten. This makes the system useful for both plant disease identification and basic tomato fruit health classification.
